# 数据范围

原始数据在完整本地工作区保留，**本公开仓库不提供原始Excel、CSV或宏观数据库**。

本地资产包括352条项目记录、904家企业、499行历史关系；去重后为331个项目组，433个有标签的项目与角色单元用于历史匹配评价。记录、项目组、回答和角色单元不是相同计数单位。

原始项目、企业和关系CSV的本地位置为 `data/test_sources/casebank_enterprise_matched/`。宏观数据库本地位置为 `vendor/gba/data/processed/agent_database.sqlite`。使用前需取得适用授权，不能据本说明推断原数据已被许可公开再分发。

公开测试使用代码内合成输入。缺失资料保持未知，不将其当作无能力、零风险或已通过。
