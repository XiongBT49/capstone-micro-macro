## 本地证据导航

`index.json` 保留对应本地文件的相对路径与用途，不包含原始证据正文。使用 `python capstone.py results` 时，程序按当前文件是否实际存在报告可用性；公开克隆缺少原件属于预期。

完整本地证据主要位于 `Capstone报告/验证体系/实验/`、`output/integration/` 和 `validation/`。日期及批次名仅用于追溯来源，不代表多套当前研究计划。

不同实验设置、项目家族和重复层次需要分开分析，不将回答数、窗口数或机制数累加为独立项目，也不将上述比例合并为系统总准确率。

研究主线见[研究计划](../research/PLAN.md)，剩余任务见[后续计划](../research/NEXT_STEPS.md)。
