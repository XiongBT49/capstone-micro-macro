# 微观采购评分复现实验

原实验以六个项目比较三种组织方式。本次从其余 346 个案例中按固定种子抽取三个香港项目，分别为粉岭北公屋、小西湾幼稚园和元朗公屋。两个项目属于公屋，新增样本的行业和地区覆盖仍有限。

两批均使用 deepseek-flash、每类两家候选、完整讨论与同一份 1 至 5 分量表。评审隐藏组织标签，每份输出交换评分顺序后评两次。下游阶段的共同输入取自多 agent 组的上游产物。

## 解释范围

三组使用的模型调用量不同，单 agent 多轮自审组用于检验多轮推敲本身能带来多少收益。评审与生成使用同一个模型，尚未经人工校准。上述分数衡量微观采购文书与决策的模型评分。项目结算、工期及历史企业 Top-3 各有独立指标。

## 新增批次的任务差异和用量

企业投标决策的综合配对分差为 +0.366（23 对），评标与定标为 −0.092（10 对），均以单 agent 一次决策为对照。新增三例的主比较共 50 对，综合评分多 agent 较高 27 对，相同 8 对，较低 15 对。

本批生成 165 份阶段输出，有 1 份多 agent 投标意向决策触发降级，按既有规则排除后，164 份进入逐份评分。有 1 次多轮自审与多岗位组的辅助 A/B 评审在重试后仍返回无效 JSON。原始记录均保留。主比较采用逐份评分。

三组的阶段生成请求分别为单次决策 90 次、多轮自审 317 次、多岗位 798 次。另有共享成员配置调用，评审请求 675 次。运行前后账户余额减少 ¥21.63。
