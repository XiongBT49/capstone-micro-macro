# S4与D3固定四次调用实验：删减版解读

本文件为按要求删减后的展示副本；完整原始实验保存在资料包之外。其余质量评分、过程失败和费用未因本次删减而调整。

主测试中，S4质量均分71.36，D3为72.64；分数差1.28分，相对变化1.79%。

项目组配对重采样95%区间：分数差[-0.01, 2.87]；相对变化[-0.01, 4.10]%。预先设定的目标是相对提升8%，实际结果独立报告。此前70分与75.6分只是目标计算示例。

按本轮S4主测试均分计算，相对提升8%要求D3达到77.07分，评分满分为100。

这是企业推荐决策实验。质量分来自相同模型、隔离上下文、交换位置两次的匿名自动评价；不是人工专家评分。人工评分表留空，供后续独立复核。

## 优化了哪些内容

1. 保留433条原记录、12家冻结候选、原企业事实与历史标签，事实修改0项、外部事实新增0项、标签修改0项。
2. 将原材料压缩为可引用事实表，增加来源定位、值哈希与引用ID，显式区分已提供信息与未知。
3. 统一结构化终稿：完整候选排序、最多3条依据、2条风险、2条待核查项；各机制采用相同输出契约。
4. 固定四次调用和相同输出上限，允许修复早期无效意见；完整记录每步可靠性、排序和依据变化。
5. 增加双顺序匿名评分、实际Token计费和G3消融；开发、验证、测试查询按项目组划分。
6. 评分理由的长度限制另做预先声明的辅助敏感性分析；主结果和失败记录不改写，不发起重试。

## 解释边界

原始433条及标签已经被检查，本轮是回顾性比较。新查询组划分没有重拟合继承的原五折OOF历史，历史证据可能跨越新开发/验证/测试阶段，不能称为全新未见的前瞻验证。
生成和评价使用同一模型，匿名和交换位置不能完全消除共同偏好；需要专业人士或独立模型复核。全部temperature=0，G3同角色独立请求可能给出相同意见，不等于三个独立人类专家。
8%是事前目标；没有为达到该数字调整标签、选择有利记录、覆盖历史评分或把自动分数当成现实盈利。

原始证据长期保存于capstone/results/experiments/capstone_micro_s4d3_equal_calls_20261120_budget60/；原40元阶段的完整部分记录单独冻结。
