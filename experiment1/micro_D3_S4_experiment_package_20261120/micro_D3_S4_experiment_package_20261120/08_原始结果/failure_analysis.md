# 本轮微观实验的限制与失败诊断

本文件为按要求删减后的展示副本；完整原始实验保存在资料包之外。其余质量评分、过程失败和费用未因本次删减而调整。

岗位讨论已接入真实模型并完成全部请求，但结果没有达到相对提升 8% 的目标。严格主测试中，D3 对 S4 相对提升 1.79%，95% 区间跨零；预声明的理由长度敏感性分析恢复全部 295 条测试配对后，相对提升约 1.41%，区间约 [0.33%, 2.78%]。后者支持小幅自动代理分数优势，不能替代严格主结果，也不能证明达到 8%。

早期岗位意见的格式失败较多，限制了讨论可用的材料：

| 过程指标（全部记录） | S4 | D3 |
| --- | ---: | ---: |
| 至少一份早期意见无效 | 68/433（15.70%） | 187/433（43.19%） |
| 早期无效步骤 | 85 | 227 |
| 最终定稿有效 | 429/433（99.08%） | 432/433（99.77%） |
| 最终 Top1 改变历史第一名 | 18/433（4.16%） | 20/433（4.62%） |

D3 全部 228 个无效步骤中，154 次因依据条目超过规定的 3 条，49 次因引用未提供或不存在的证据 ID。这些是结构校验失败，不能都解释为业务判断错误；但按冻结协议，相应意见作为无效占位符进入汇总，经理不能使用其建议。最终输出较少回退，表明汇总阶段常能恢复格式有效性，不能证明被丢弃的岗位信息已被恢复或其语义准确。

历史排序仍是强参照。D3仅改变20条第一名。12家候选的历史覆盖固定为311/433（71.82%）。证据不足、原历史信号有效和提示中的历史排名都可能影响保守排序，本轮没有单独识别各自的因果贡献。

S4 与 D3 的比较同时改变了串行自检、独立意见汇总和岗位分工。更接近岗位净价值检验的 G3 消融保持“三份独立意见＋经理”结构一致；无论严格主解析还是长度敏感性解析，D3 对 G3 的平均差值均略为负，区间跨零。因此不能把 D3 对 S4 的小幅优势直接归因于岗位分工。格式失败率也随机制变化，需要在下一轮预先固定改进格式方案并重新对照。

评分来自同一模型的匿名自动代理评价，缺少真实人工专家评分；引用 ID 存在、风险陈述更多和待核查项更多，都不等于内容真实或业务风险判断更准。原始 433 条为此前已分析的回顾数据，新的查询组划分未重拟合继承的 OOF 历史。本轮没有运行生命周期模拟，没有验证现实合同、成本、收入或利润，不能推断现实项目盈利提升。

本诊断只新增离线分析文件，未改原始响应、严格主评分、失败记录或冻结归档；未新增模型调用。
