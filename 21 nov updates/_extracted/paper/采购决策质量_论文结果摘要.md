# 多岗位协作能否提高工程采购决策质量？

在本研究的 12 个微观评分案例中，多岗位 agent 协作提高了采购决策文本的模型评分。相对于单 agent 一次决策，12 个项目的平均分差全部为正。单 agent 加入多轮自审后，差距缩小，多岗位组仍在 10 个项目中领先。两种对照中，分差最大的维度都是风险与权衡。

## 微观决策质量

实验涵盖业主招标策划、企业投标决策、投标文件、评标与定标四类任务。各组对同一任务收到相同的阶段输入。每份输出按六个维度评分，每项 1–5 分。先平均两次评审，再对六项等权平均。下表将每个项目赋予相同权重，分差以多岗位组得分减去基线得分计算。

| 对照基线 | 可配对任务数 | 项目等权平均分差 | 按项目重抽样的 95% 区间 | 多岗位组项目胜 / 平 / 负 |
|---|---:|---:|---:|---:|
| 单 agent 一次决策 | 217 | +0.180 分 | [+0.151, +0.208] | 12 / 0 / 0 |
| 单 agent 多轮自审 | 218 | +0.074 分 | [+0.031, +0.116] | 10 / 1 / 1 |

按同一任务比较各维度时，多岗位组的“风险与权衡”评分相对两条基线分别提高 0.509 分和 0.252 分。“可执行性”相对一次决策提高 0.253 分，相对多轮自审仅提高 0.018 分。“证据忠实”和“内部一致与约束遵守”的分差在两种对照中都接近零。[完整六维评分与逐项目结果](微观采购质量/micro-org-extension12-20261119/十二例评分汇总_核定.md)

这些分数来自 DeepSeek 模型评审，尚待人工评审校准。各组计算用量不同，固定的下游输入取自多岗位组的上游输出。因此，数据支持本实验配置下的评分优势。要单独识别角色分工的贡献，还需要控制推理预算和上游输入来源。

## 微观决策进入宏观仿真后的结果

另一个实验有 12 个端到端案例，与上述评分实验重合的项目为 CASE-0001 和 CASE-0014。两组都结算的 11 例中，多 agent 的模拟工程质量均值为 0.78086，单 agent 为 0.78130，多 agent 在 4 例更高、7 例更低。CASE-0315 两组均在采购阶段停工，未进入竣工质量比较。GBA 以设计质量的 40% 和施工质量的 60% 计算该指标。这组结果验证了采购合同可进入宏观仿真并产生可比较的项目结果，尚未观察到一致的竣工质量增益。[端到端原始对照](端到端案例/paired_results.csv)
## 论文分析前的离线复核
